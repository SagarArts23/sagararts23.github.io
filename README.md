# रंगसागर Studio

Bilingual (नेपाली / English) portfolio site for Sagar Niraula (रंगसागर) — wall art (भित्ते कला), tattoo (ट्याटु)
and canvas (क्यानभास) work, Nepal.

Live at **https://sagararts23.github.io/**

## Layout

- `index.html` — the whole site, self-contained. No build step.
- `img/` — artwork photos (max 1600px, ~80% JPEG)
- `video/` — studio clips (720p30 H.264, no audio)

Pushing to `main` redeploys automatically.

## QR

`qr/` holds QR codes pointing at the live site:

- `qr-card.png` — share card for Instagram / WhatsApp (1080×1350)
- `qr-logo.png` — QR with the brush mark in the middle
- `qr-print.png` — plain black on white, 2000px, for printing
- `qr.svg` — vector, scales to any size

All are error-correction level H, so the centre mark costs no reliability.
